# Architektur

## Frontend
- Vite + React (aber maybe auch einfach nextjs)
- shadcn

## Backend
- Spring Boot in Java (Maven)
- Postgres-Datenbank (mit Möglichkeit zur SQlite)

## Auth
- Im Basisfall für self-hosted Username/Passwort
- Als Hosting-Option kann es nachträglich erweitert werden um Google, Discord usw.

## Hosting / Versionierung
- Github

## Paket
- 3 Container (Frontend, Backend, Datenbank)
